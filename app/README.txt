Team Pool Tracker - trial build 0.1

TRY IT ON YOUR COMPUTER
1. Open a terminal in this folder and run: python3 -m http.server 8000
2. Open http://localhost:8000 in Chrome.

PUT IT ON THE INTERNET (Cloudflare Pages, free)
1. Sign in at dash.cloudflare.com, go to Workers and Pages, Create, Pages, Upload assets.
2. Name the project, then upload the files in this folder (not the tests folder).
3. After it deploys, open the project, go to Custom domains, and add teampooltracker.com.

INSTALL ON A PHONE
iPhone: open the link in Safari, Share, Add to Home Screen.
Android: open the link in Chrome, menu, Install app.
Open it once with internet, then it works offline.

FIRST USE
Settings: enter team name. Players: check names. Home: Start match.
